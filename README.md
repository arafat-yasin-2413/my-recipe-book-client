# 🍽️ Recipe Book

A full-featured React-based web application where users can explore, add, update, and manage recipes. Authenticated users can create their own recipe list and view details of each recipe. Built with modern tools and a clean UI using Tailwind CSS and DaisyUI.

## 🔗 Live Site

[🌐 Visit Live Site](https://recipe-book-app-e138e.web.app)

## ✅ Features

- 🔐 **Authentication system** with protected routes (Login/Signup via Firebase)
- 🍽️ **Top 6 Recipes section** on homepage loaded dynamically from server
- ➕ **Add new recipe** functionality (restricted to logged-in users)
- 📋 **My Recipes** section to manage your own added recipes
- 🔍 **View full recipe details** with dynamic route and secure access

## 🧑‍💻 Tech Stack

**Frontend:**

- React 19
- React Router v7
- Tailwind CSS v4
- DaisyUI
- Firebase Auth
- Lottie for Animations
- React Toastify
- SweetAlert2

**Build & Tools:**

- Vite
- ESLint
